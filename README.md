# MAAS Tally Migration

A Frappe/ERPNext app for importing Tally XML data into ERPNext.

This app includes migration tooling for:

- Tally masters
- Chart of Accounts
- Customers and Suppliers
- Items, Warehouses, UOMs
- Opening invoices
- Opening stock
- Opening journal entries
- Daybook vouchers
